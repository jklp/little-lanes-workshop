# Simple Kanban

Can you build me a trello like app. Very basic so there's swimlanes for backlog, in progress and done. no option to create more or reorder

cards are very basic, title and description. nothing else - no priority, severity, etc. 

and then have multiple users log in. again very basic, users are first name and last, and password. no google logins, etc 

and each user can create their own boards. no sharing or inviting to organisation

also no mobile version - desktop only

Make it look like an Apple designed app. So no extra detail - keep it clean and simple.
